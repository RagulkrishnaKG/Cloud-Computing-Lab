# Cloud Computing Laboratory

This repository contains programs, configuration files, commands, and sample outputs for the Cloud Computing Laboratory experiments based on the laboratory manual.

## Repository Structure

Each experiment is organized in a separate folder. Code, configuration files, commands, and output are kept together for easy execution and evaluation.

## Experiments

1. Introduction to Cloud Computing
2. Cloud Service Setup
3. Cloud Application Deployment
4. Google App Engine
5. CloudSim Simulation
6. CloudSim Scheduling
7. Docker Containerization
8. Docker Containers and Images
9. Nginx Container
10. MongoDB Container

## General Requirements

The exact software and tools required for each experiment are described inside its respective README file.
